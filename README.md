## Asking for Help

Do **not** send only screenshots of code errors in WhatsApp.

Instead:

1. Push your latest code to your own GitHub repository.
2. Open **Issues → New Issue**.
3. Use the **C++ Troubleshooting** issue template.
4. Paste the complete terminal error.
5. Explain what you already tried.
6. Mention **@shiddiqeuy**.
7. Share the Issue link in the WhatsApp group.

> Before asking for help, try at least one solution yourself.
