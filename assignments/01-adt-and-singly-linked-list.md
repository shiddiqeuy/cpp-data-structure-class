# Assignment 01 — C++ Data Structures: ADT & Singly Linked List

## Description

In this assignment, you will practice fundamental Data Structure concepts using C++.

The assignment combines two topics:

### Part 1 — ADT / Struct

Build a simple Student Grade System using:

- `struct`
- variables
- functions
- input/output
- `if / else if / else`
- array of struct
- `for` loop

### Part 2 — Singly Linked List

Practice:

- node
- pointer
- dynamic allocation
- `first`
- `insertFirst`
- `insertLast`
- `insertAfter`
- traversal using `while`
- search
- delete / deallocation
